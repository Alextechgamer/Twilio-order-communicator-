# StoreCanvas

Self-hosted WooCommerce **product options** + **live mockup placement** + **print-ready exports**.

Version: **0.8.0**

## What's in 0.8.0

1. **Live price** — option changes update displayed product price client-side
2. **Block/cart polish** — cart/checkout block compatibility; shortcodes for block themes
3. **Orders SC Art** — admin column + filter for orders with custom art

## Shortcodes (block themes)

- `[storecanvas_options]` — product option fields (use on single product)
- `[storecanvas_customizer]` — live mockup canvas when enabled

## Requirements

WordPress 6.0+, WooCommerce 7.0+, PHP 7.4+, PHP GD for composites.

## Install

Copy `storecanvas/` → `wp-content/plugins/`, activate.
