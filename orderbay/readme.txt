Self-hosted WooCommerce ops toolkit: invoices, order ops, email rules, digests, CSV export, catalog helpers, dashboard.

== Description ==

Orderbay is independent of Twilio Order Communicator (SMS/voice) and StoreCanvas (personalization).

PDF uses browser print. Digests and rule emails use wp_mail + WP-Cron.
