Self-hosted WooCommerce ops toolkit: invoices, tracking URLs, RMA, SLA, digests, search.

== Description ==

Independent of Twilio Order Communicator and StoreCanvas.

Admin order search also matches invoice number, RMA number, and tracking number meta.
