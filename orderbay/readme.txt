Self-hosted WooCommerce ops toolkit: invoices, fulfillment, pick lists, tracking, credit notes, digests, CSV.

== Description ==

Orderbay is independent of Twilio Order Communicator and StoreCanvas.

* Warehouse pick list bulk HTML (by SKU)
* Tracking number/URL + optional customer email (default off)
* Credit note document + CN- numbers
* Auto needs-attention on selected statuses (default off)
